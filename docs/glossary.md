# Glossary

This glossary contains key technical, security, and agricultural domain terms used throughout the Mbegu Link ecosystem.

| Term | Category | Definition |
| :--- | :--- | :--- |
| **Alembic** | Technical | A lightweight database migration tool for use with SQLAlchemy to track and apply structural PostgreSQL database schema changes. |
| **Append-Only Audit Trail** | Security | A secure logging design pattern where records can only be added, preventing users or coordinators from modifying or deleting historical tracking actions. |
| **Bcrypt** | Security | A secure cryptographic password-hashing function designed to protect user credentials with built-in salting against brute-force attacks. |
| **Community Seed Bank (CSB)** | Domain / Product | A localized community facility where farmers collectively store, manage, and conserve indigenous or regional seed varieties. |
| **FastAPI** | Technical | A modern, high-performance web framework for building APIs with Python based on standard Python type hints. |
| **Gene Bank** | Domain / Product | A highly controlled facility or repository used to collect, store, and preserve genetic material from living organisms (e.g., plant seeds) to maintain agricultural biodiversity. |
| **GeRRI** | Domain / Product | Genetic Resources Research Institute. The national genebank entity in Kenya responsible for institutional seed conservation, duplication, and professional support. |
| **HTTP Strict Transport Security (HSTS)** | Security | A web security policy mechanism that forces web browsers to communicate with a website exclusively through secure, encrypted HTTPS connections. |
| **HttpOnly Cookie** | Security | A security attribute applied to cookies that prevents client-side scripts (like JavaScript) from accessing token data, mitigating XSS extraction risks. |
| **JWT (JSON Web Token)** | Security | A compact, URL-safe means of representing claims to be transferred between two parties. Used in Mbegu Link for short-lived, encrypted 5-minute user session authentication. |
| **Lot Code / Lot ID** | Domain / Product | A unique tracking identifier assigned to a specific batch of seeds within the registry system to ensure traceability from source to vault. |
| **MVP (Minimum Viable Product)** | Domain / Product | A product release strategy containing only core mandatory features (such as online-only actions, in-app notices) built to gather initial stakeholder usage feedback. |
| **OTP (One-Time Password)** | Security | A short-lived passcode delivered dynamically (e.g., via SMS) to provide a single-use authentication factor for farmer seed custodians. |
| **Pydantic** | Technical | A Python data validation and serialization library used by FastAPI to enforce strict data layout typing on inbound requests and outbound responses. |
| **Safety Duplication** | Domain / Product | The systematic backup process where a duplicate sample of an endangered or critical seed batch is deposited at a national genebank (GeRRI) for absolute redundancy. |
| **Seed Custodian** | Domain / Product | A farmer role responsible for physically keeping, growing, and safeguarding agricultural seed batches within local target communities. |
| **SQLAlchemy** | Technical | An Object-Relational Mapper (ORM) library that allows Python code to securely query and manipulate database objects inside PostgreSQL without writing raw SQL strings. |
| **TLS (Transport Layer Security)** | Security | A cryptographic protocol designed to provide end-to-end communications privacy and data encryption safety across networks. |
| **XSS (Cross-Site Scripting)** | Security | A security vulnerability typically found in web applications that allows attackers to inject malicious client-side scripts into web pages viewed by other users. |
